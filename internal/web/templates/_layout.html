Find more servers

Pick servers marked remote or hosted (an https://…/mcp or …/sse URL). Servers you run yourself with npx or uvx can’t be added here.

  • Official MCP Registry — the protocol’s own catalog
  • Smithery — many hosted servers, with remote URLs
  • Glama — large directory, filter by hosting
  • mcp.so — community directory
  • modelcontextprotocol/servers — reference servers and a long list of official integrations
