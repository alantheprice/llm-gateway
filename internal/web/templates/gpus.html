My GPUs

Your GPUs

Each linked GPU runs a small agent that connects out to this gateway, so you don't open ports or set up a VPN. A linked GPU is private to you until you share it with named people. You control who can use it, whether it helps serve platform models, and you can see who used it. Link tokens are separate from your API keys. Read the full guide →

What do the statuses and controls mean?
  • connected the agent is online and relaying for its engines.
  • not connected the token exists but no agent is using it. Run the install script, or check the agent's log.
  • paused the agent stays connected but nobody is routed to it. Resume any time.
  • revoked the token no longer works. Create a new link if you still want this GPU.
  • Share names people who may call your GPU with their own API keys. Remove them with ×. Share with everyone opens it to every signed-in user.
  • Platform models: if an admin lists your GPU in a shared model (like qwen3.8-27b), it only serves that model once you tick the box. More →
  • To replace a token, create a new link, run its script, then revoke the old one.
